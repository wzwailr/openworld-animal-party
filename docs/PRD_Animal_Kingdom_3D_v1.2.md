## 1. 产品定位与核心目标

### 1.1 产品定位
《动物王国：仲夏森林漫游记》是一款浏览器原生 Web 3D 的**儿童专属**第一人称治愈童话微缩王国漫游作品。儿童无需下载客户端、无需安装插件，打开网页即可化身被森林居民期待的小客人，踏入一片由全体小动物合力搭建的夏日欢乐乐园。整体氛围明亮温柔，所有动物友善热情，专为孩子打造无压力、可自由闲逛、随时互动的童话天地。

### 1.2 核心体验目标
1. **柔和治愈的童趣视听共振**：低饱和马卡龙手绘光影、缓慢浮动柔光粒子、清澈 3D 立体八音盒 / 童谣声场，全程护眼护耳，带来松弛、快乐的沉浸感。
2. **层层递进的童话探索动线**：连贯无缝地形由浅入深，从入口梦幻小路走到热闹动物派对，最终登上高空树屋瞭望整片森林，全程步移景异。
3. **极简低负担轻柔童话互动**：摒弃战斗、闯关、限时惩罚，仅保留打招呼、偶遇发光小惊喜、拍照记录、聆听乐曲等轻松玩法，无任务催促感。
4. **温和自然轻科普**：不同场景搭配对应栖息地的软萌小动物（无恐怖物种），潜移默化让孩子认识多样的森林与水岸动物。**注**：科普仅覆盖主要栖息地动物，个别「魔法幻想彩蛋」不参与科普（见 2.3）。

整片仲夏森林是小动物们合力搭建的夏日乐园，所有小动物提前布置灯光、乐队、游船与信件，只为迎接前来游玩的小朋友。**你不是闯入者，是被所有动物期待的小客人**；所有灯光、乐曲、小礼物，都是森林小动物主动送出的温柔馈赠。

## 3. 核心交互与玩法系统（儿童向轻量化，无任务压迫感）

### 3.1 漫游控制系统 (Locomotion)

- **自由探索模式 (Free Roam Mode)**
  - **PC/Mac**：`W/A/S/D` 行走、`Shift` 慢速小跑、`Space` 轻跳、鼠标拖拽视角；移动速度舒缓，避免眩晕。
  - **移动端 / 平板**：左下角虚拟摇杆移动，右半区滑动转向；支持可关闭的陀螺仪体感；双指缩放画面近距离观察小动物。
  - **地形物理**：全程圆润平缓地形，无悬崖深坑；重力柔和，台阶自动吸附，无坠落惊吓；树木、石头边界柔和阻挡，无法穿模。
  - **童趣静坐机制**：原地停留 30 秒，角色自动蹲坐看花、追蝴蝶，粒子柔光弱化，BGM 放缓，给孩子放空休息空间。

- **水獭巡航放空导览模式 (Cinematic Tour Mode)**
  一键切换纯观光模式，镜头缓慢跟随核桃小船自动漂流，沿途柔和转向风景；无文字弹窗、无对话打扰，仅保留溪流与童谣背景音乐。

### 3.2 动态感知互动系统 (Smart Interaction)

1. **儿童友好视线准心反馈**：中央柔和光点准心；扫过可互动对象时光点扩张为**小兔子头像动效**，浮现极简圆润文字「点击打招呼」。

2. **动物交响互动台**：点击兔子指挥家弹出简易乐谱面板，切换《森林晨曦童谣》《盛夏圆舞曲》《星光晚安曲》；全场动物乐队同步变换演奏动作，音乐缓慢淡入淡出。

3. **猫头鹰童话信件手册**：林间散落多封小动物手绘信件，内容为童趣日常涂鸦短句（浣熊分享蘑菇浆果、乐队记录新曲子、水獭夸赞溪流花瓣）；集齐后猫头鹰送出完整手绘童话画册，自动存入「游记图鉴」。

4. **林间小夜灯偶遇奇遇（弱化任务属性）**：散落的小路灯非强制收集，孩子路过随手点亮即可触发泡泡、星光小特效；全部点亮后自动触发全域彩色星光缓慢飘落、百鸟轻鸣的全景惊喜动画，**无弹窗奖励提示**，纯视觉浪漫馈赠。

5. **全域自然轻交互（无门槛）**：花草、树干、荷叶、风铃均可触碰，反馈全部柔和童趣（碰花飞彩蝶、抚树干冒小星星、踩草弹软泡泡），无刺眼爆炸特效。

### 3.3 新手引导 (Onboarding)

针对低龄儿童的渐进式、无文字示范引导：

1. **引路松鼠示范式引导**：首次进入时，松鼠在前方跳一步、孩子跟随一步，通过「示范 + 跟随」自然学会前进/移动，不依赖文字说明。
2. **视角吸引式教学**：引导阶段让一只蝴蝶从眼前飞过，吸引孩子转动视角追看，自然掌握视角控制。
3. **可视化按键提示**：屏幕角落以卡通图标（非纯文字）展示当前推荐按键/手势。
4. **可跳过**：引导可随时跳过，供已会操作的孩子 / 家长直接进入自由漫游。
5. **引导结束即隐身**：完成引导后松鼠回归常态，不再持续提示。

## 4. 视听与沉浸特效（VFX & Audio）儿童适配规范

### 4.1 动态环境特效 (VFX)

1. **柔和体积丁达尔光束**：树冠缝隙缓慢流动浅金色柔光，光束内漂浮细碎低亮度光尘，亮度全程可控、绝不刺眼。
2. **全域轻柔粒子系统**：
   - 蘑菇林：慢速马卡龙彩色孢子，漂浮松弛、缓慢消散；
   - 溪流谷：水车水雾 + 转瞬即逝的迷你淡彩虹；
   - 全局：柔和光斑、全天可见萤火虫泡泡、夜晚圆润星光粒子；
   - 所有流星雨 / 庆典特效为缓慢飘落的糖果色光点，**无密集强光闪烁**（频率约束见 7.2）。
3. **卡通柔和动态水体**：水面浅透干净，浅滩清晰可见鹅卵石；接触水面仅生成细碎白色软泡沫，镜面高光柔和，无幽深暗水区域。
4. **小动物软萌循环动画**：所有动作缓慢柔和（呼吸起伏、轻眨眼、慢摇尾巴、慢悠演奏）；造型圆脸蛋短四肢，**剔除尖牙、利爪、尖锐棱角**，规避儿童恐惧元素。

### 4.2 3D 空间音频矩阵（低龄听觉友好 · 无台词）

> **音频原则（v1.2 定稿）**：全产品**无台词、无配音**。小动物只通过**拟声语气音**（笑声、呼唤声、咕噜声等）与**童谣哼唱**（无歌词或简单无意义音节）表达情绪，避免台词内容带来的合规审查成本，同时保持「无文字弹窗」的纯净体验。

1. **分层柔和环境底噪**：根据场景平滑淡入淡出，音量偏低（林间风声、树叶沙沙、清脆鸟啾、远处溪流），无轰鸣巨响。
2. **空间点位立体音效**：广场乐队声音随距离自然变轻；水车嘎吱声、蛙鸣、动物叫声有清晰方位感；VR/WebXR 模式搭配头部定向立体声。
3. **自适应材质脚步声**：踩草地、木板、石桥、浅水自动切换清脆柔和脚步声。
4. **专属儿童音频规则**：BGM 为八音盒 + 小动物简易乐器合奏童谣；小动物语气音为稚嫩软糯童声感（无语言）；可单独关闭风声、虫鸣环境音，只保留乐曲。

## 5. 界面设计规范 (UI/UX) 极简无干扰儿童版

**设计总原则**：极低存在感、卡通圆润字体、浅淡磨砂透明、不遮挡童话画面。

1. **常态漫游画面**：仅保留中央微弱准心，全屏纯净 3D 场景，无多余 UI 遮挡。
2. **右上角磨砂透明迷你工具条（圆角卡通按钮）**：
   - 🎵 音乐音量开关（滑动条柔和渐变）
   - 📷 照片模式：一键隐藏界面，可调柔和景深，叠加卡通动物边框与森林邮戳，**仅本地保存**手绘风明信片
   - 📖 游记图鉴：动物图鉴 / 童话信件画册 / 点亮小夜灯记录 / 乐曲收藏
   - 🥽 WebXR / VR 模式一键切换
3. **左下角淡入淡出提示区**：进入新场景时缓慢浮现浅彩文字「📍 仲夏动物庆典广场」，3 秒自动消失；显示当前漫游模式（自由闲逛 / 水獭小船观光）。
4. **长时间闲置自动隐藏全部 HUD**，仅保留准心；VR 模式移除 2D 悬浮按钮，采用视线凝视触发交互。

## 6. 儿童安全与合规（新增 · 儿童专属强制要求）

1. **隐私与数据最小化**：不采集任何儿童个人信息；无账号系统、无聊天、无 UGC（用户生成内容）、无第三方追踪 SDK、无广告 SDK。
2. **无外链与无广告**：产品内不出现任何外部链接、跳转或广告位。
3. **家长门（Parental Gate）**：仅当未来引入外部链接 / 购买 / 分享到站外时，需加入家长验证门槛；当前版本无此类功能。
4. **照片本地化**：拍照明信片仅在本地生成与保存，**不传服务器、不上传云端**。
5. **内容安全**：全场景无恐怖元素、无武器、无暴力、无暗黑色调；动物均为友善形象（已在 4.1.4 固化）。
6. **音频安全**：默认音量适中，设置硬性音量上限；提供一键静音。

## 7. 无障碍与用眼健康（新增）

1. **光敏感安全**：所有特效的**闪烁 / 亮度突变频率不超过 3 次/秒**（参照 WCAG 对光敏性癫痫的 3 Hz 限制）；不出现高对比度密集条纹或快速频闪。
2. **减弱动态效果开关 (Reduced Motion)**：提供「柔和模式」开关，开启后关闭/大幅降低粒子、光斑移动与镜头晃动，照顾易眩晕或光敏感儿童。
3. **视线凝视交互（可选）**：将「视线凝视触发」从「仅 VR 模式」扩展到桌面 / 移动端的**可选交互方式**——长时间注视 = 点击，降低低龄儿童对手部精细操作的门槛。
4. **单一/单手操作模式**：支持单手完成移动 + 交互的简化操控选项。
5. **用眼提醒**：每 20 分钟出现一次柔和休息提示（儿童产品惯例），可关闭。
6. **色觉友好**：交互提示不单靠颜色区分，关键状态同时用形状 / 图标 / 动画表达。
7. **文字可读性**：所有文字简短、圆润、大字号、浅底高对比，配图标。

## 8. 性能与多端适配基线（新增）

1. **帧率目标**：
   - 桌面 / 旗舰移动设备：≥ 60 FPS；
   - 中端移动设备：≥ 30 FPS。
2. **设备分级（三档自动降级）**：
   - **高档**：全特效（体积光、完整粒子、镜面水体反射）；
   - **中档**：保留体积光 + 精简粒子、简化水体；
   - **低档**：关闭体积光、大幅精简粒子、烘焙光照替代动态光。
3. **首屏可交互时间**：≤ 8 秒；通过资源流式加载、渐进式展示与低清占位图过渡实现。
4. **资源预算**：单场景初始加载资源需有上限约束（技术方案阶段定具体数值），避免移动端内存溢出。
5. **VR 防眩晕**：画面边缘虚化、降低移动速度、提供传送式移动选项。

## 9. 项目演进与交付阶段规划

- **Phase 1（核心场景 MVP 验证）**：搭建场景 3 仲夏动物庆典广场，完成儿童向慢行操控、基础物理碰撞、柔和丁达尔光影、卡通水体、完整动物交响乐队与 3D 空间音频，验证整体童趣治愈氛围。
