# 《动物王国：仲夏森林漫游记》产品设计规范文档 (PRD)

> **版本**：v1.0  
> **状态**：已定稿 (Ready for Architecture & Dev)  
> **类型**：Web 3D / WebXR 沉浸式第一人称交互漫游体验  
> **视觉基准**：奇幻童话手绘光影风格（参考原画：巨型蘑菇、溪流森林、动物交响乐团、阳光丁达尔光斑）

---

## 1. 产品定位与核心目标

### 1.1 产品定位
《动物王国：仲夏森林漫游记》是一款基于浏览器原生 Web 3D 技术的 **第一人称沉浸式治愈系童话微缩王国漫游体验**。用户无需下载安装任何插件或客户端，打开网页即可像缩小后的旅人一样，置身于一个充满生机、温暖光影与奇幻动物乐团的森林世界中。

### 1.2 核心体验目标
1. **极致氛围与视听共振**：结合手绘/卡通风格光影、动态体积光（丁达尔效应）、流体水面、光尘粒子与 3D 空间立体声场，带来深度疗愈感。
2. **步移景异的自然探索**：通过一条自然连贯的地形动线，让用户从幽静神秘逐步走向繁华庆典与高空俯瞰。
3. **轻度生动的童话互动**：非复杂的游戏机制，而是以“与居民对话/互动”、“寻宝点灯”、“拍照留念”、“聆听音乐演奏”为主的沉浸交互。

## 2. 场景世界观与五大动线设计

整个体验构建在一个连续无缝的 3D 地形中，随着用户第一人称走动，从幽暗静谧过渡到热闹狂欢，最后登上森林之巅：

```
[场景 1: 月光门入口] 
       ↓ (穿越微光幽谷与荧光草径)
[场景 2: 巨型蘑菇森林] 
       ↓ (循着管弦乐声与暖金晨光)
[场景 3: 仲夏庆典广场] (核心视觉高潮·原画场景)
       ↓ (穿过藤蔓石拱桥 / 乘水獭小木船)

```

## 3. 核心交互与玩法系统

### 3.1 漫游控制系统 (Locomotion)
* **自由探索模式 (Free Roam Mode)**：
  * **PC/Mac 端**：`W/A/S/D`（前后左右行走）、`Shift`（林间慢跑加速）、`Space`（跳跃）、鼠标锁定拖拽视角。
  * **移动端 / 平板**：左下角虚拟摇杆移动，屏幕右半区滑动调整视线；支持设备陀螺仪体感环顾。
  * **物理碰撞与地形响应**：具有重力、斜坡行走能力与边界阻挡（无法穿透大树、悬崖与深水区），支持台阶吸附。
* **水獭巡航导览模式 (Cinematic Tour Mode)**：
  * 一键切换“纯享观光模式”。镜头自动平滑附着在水獭的木船上，顺溪流缓缓漂流，镜头沿途平滑转向重点景色，配合舒缓旁白与原声音乐。

### 3.2 动态感知互动系统 (Smart Interaction)
* **视线对焦准心 (Reticle Feedback)**：
  * 屏幕中央设有微弱光点准心。
  * 当准心掠过可交互对象（NPC、灯笼、蛋糕、信件）时，光点扩展为**金色爪印/放大镜动效**，并浮现轻量交互提示（如 `[E] / 点击聆听`）。
* **交响乐互动台 (Concert Conductor)**：
  * 点击兔子指挥家，可调出乐谱面板，切换《森林晨曦》、《盛夏圆舞曲》、《星空夜曲》等曲目，乐队动作与背景节奏实时联动。
* **猫头鹰故事信箱 (Memory Postbox)**：
  * 探索各个角落收集散落的 5 封动物信件，每封信包含一段手绘插画故事与森林背景介绍，解锁后可随时在“游记手册”中翻看。
* **林间七盏提灯奇遇 (The 7 Lanterns Quest)**：
  * 分布在五个场景中的失落路灯。全部点亮后，场景将触发全局“金色流星雨与百鸟齐鸣”全景庆典动画。

## 4. 视听与沉浸特效（VFX & Audio）技术规范

### 4.1 动态环境特效 (VFX)
1. **体积光束 / 丁达尔神光 (God Rays)**：从树冠缝隙向下投射的自适应动态光柱，光柱内包含微小悬浮光尘。
2. **环境粒子系统**：
   * 蘑菇林：飘落的慢速荧光孢子。
   * 溪流区：水车与瀑布激起的微细水雾粒子与局部微型彩虹。
   * 全局：阳光光斑 (Sun Shafts / Dust Flecks) 与夜幕萤火虫。
3. **动态水体 (Stylized Water)**：
   * 水面法线扰动、浅滩透明度渐变、物体边缘接触泡沫浪花、阳光镜面高光反射。
4. **NPC 生机微动 (Idle Animations)**：
   * 动物具备呼吸起伏、眨眼、摆尾、演奏挥臂等微动作循环，避免场景僵硬死板。

### 4.2 3D 空间音频矩阵 (3D Spatial Audio)
* **全景环境底噪 (Ambient)**：根据玩家所在区域平滑淡入淡出（林间风声、树叶沙沙声、虫鸣鸟叫、远景瀑布轰鸣）。
* **点声源空间衰减 (Positional Audio)**：
  * **庆典广场**：以乐台为中心，交响乐随距离增加产生自然空间衰减与高频空气吸收。
  * **水车谷**：木轮转动时的嘎吱声与近距离激流水声，具有明确的双耳立体声方位感。
* **动态脚步声 (Adaptive Footsteps)**：
  * 根据踩踏材质（草地、木板台阶、石桥、浅水）自动切换真实的脚步音效。

## 5. 界面设计规范 (UI/UX)

* **设计原则**：极简、沉浸、无干扰、去 UI 化。
* **HUD 布局规范**：
  * **主界面平时**：仅保留微小准心，全屏纯净呈现 3D 画面。
  * **右上角工具条 (透明磨砂玻璃质感)**：
    * 🎵 音乐音量开关
    * 📷 **照片模式 (Photo Mode)**：一键隐藏所有界面，支持调焦/景深/加盖王国邮戳，可直接生成高清明信片下载
    * 📖 **游记图鉴 (Journal)**：查看已收集信件与点亮灯笼进度
    * 🥽 **WebXR / VR 模式切换**
  * **左下角状态区**：
    * 当前所处区域名称优雅浮现（例如：进入庆典广场时淡入“📍 仲夏庆典广场”，3秒后淡出）
    * 模式切换图标（自由行走 / 乘船巡航）

## 6. 项目演进与交付阶段规划

* **Phase 1 (核心场景验证 MVP)**：
  * 搭建场景 3（仲夏庆典广场），实现第一人称流畅行走控制、碰撞、丁达尔光、水体、兔子乐团与空间音频。
* **Phase 2 (世界观动线扩充)**：
  * 连通场景 1（月光门）与场景 2（蘑菇森林），实现地形高低起伏过渡与多点声源混合。
* **Phase 3 (全场景贯通与玩法完善)**：
  * 补齐场景 4（水车谷）与场景 5（树屋村），接入水獭小船巡航路线、灯笼收集任务与猫头鹰信件系统。
* **Phase 4 (画质精修、性能优化与 WebXR)**：
  * 贴图与着色器性能调优，适配主流手机/平板高帧率运行，提供 VR 头显一键沉浸支持。
